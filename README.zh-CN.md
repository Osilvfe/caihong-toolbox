# Caihong Toolbox

[English](README.md) | 简体中文

Caihong Toolbox 是运行 Caihong Linux 的一加平板 Pro（`caihong`）图形设置工具。
它把设备设置和硬件测试集中在一个适合触屏操作的窗口中，并跟随本地 Plasma
主题、字号和强调色。

该工具已默认集成到
[Caihong Linux rootfs](https://github.com/Osilvfe/caihong-linux-rootfs)。

## 功能

### 设备总览

- 查看机型、内核、电量与温度、适配器状态、键盘和手写笔。
- 无法读取的信息保持为空，不进行猜测。

### 充电与电池

- 在正常充电和停充供电之间切换；停充供电会停止给电池充电，但保留适配器供电。
- 为当前运行期设置实验性的充电开始和停止阈值。
- 查看固件报告的健康度、循环次数、容量，以及估算的输入功率和电池功率。
- 查看识别到的充电协议（USB PD、PPS，以及可识别的 VOOC/SVOOC）和 PPS 电流上限。

### 性能与温度

- 查看 CPU 使用率、各核心当前与最大频率、调频策略、GPU 频率、系统负载和运行时间。
- 查看内存、交换和根分区使用情况。
- 按 CPU、GPU、内存、NPU、视频、摄像头、电池、电源管理、调制解调器等类别显示最高温度；
  完整热区列表可在诊断信息中查看。

### 键盘与触控板

- 顶排按键可选择标准 F1-F12，或键帽上印制的媒体功能。
- 蓝牙模式下的 F4 兼容会自动启用，不提供单独开关。
- 需要时可以开启或关闭触控板。

### 手写笔

- 开关书写反馈，并选择原厂工具和强度。
- 测试短振和笔身触控区域。
- 观察笔身双击和滑动事件，便于排查。双击行为可以设为仅计数、短振，
  或切换当前书写反馈。

### 硬件测试

- 屏幕色卡和画板，用于检查触屏与手写笔输入。
- 键盘与触控板、扬声器、麦克风、摄像头、音视频节点、网络与蓝牙、
  电池、存储，以及单个传感器。
- 所有测试都需手动开始和停止，不会在后台持续运行。

### 服务管理与诊断

- 查看并启停 Caihong 服务和定时器。
- 没有连接手写笔或键盘时，相关入口会自动隐藏。
- 复制当前诊断信息，便于反馈问题。

## 打开方式

从应用菜单打开 **Caihong Toolbox 设备设置**，或运行：

```sh
caihong-toolbox
```

窗口以普通用户运行。修改充电、键盘、手写笔或服务设置时，会通过一个权限受限的
后台程序执行，并只在需要时请求管理员授权。

如只想查看界面、不接触硬件：

```sh
caihong-toolbox --demo
```

## 安装

Caihong Linux 已默认安装。手动安装到 Arch Linux ARM：

```sh
sudo pacman -S --needed pyside6 python-gobject polkit
sudo make install
sudo systemctl daemon-reload
sudo systemctl reload dbus
```

不要重启系统 D-Bus。后台按需启动，不会作为开机服务常驻。

## 注意事项

- 只有按下操作按钮并确认管理员授权后，设置才会生效。
- 程序不会刷写内核、模块或启动镜像。
- 充电阈值仍是实验功能，只对当前运行期生效。
- 缺少对应内核接口或附件时，相关测试只能查看，不能操作。
- 麦克风录音是临时文件，关闭测试后即删除。
- 诊断信息可能包含设备地址，分享前请检查。

## 开发

需要 Python 3.11+、PySide6 6.8+ 和 PyGObject；运行测试还需要 pytest。

```sh
make check
python3 -m caihong_toolbox --demo
```
